# Indian Folk Art — Tee Design Prompts

Generated: 2026-09-27
Each prompt is written for a clean cutout: flat/solid background so it can
be background-removed and printed, original composition (not a copy of any
specific stock/artist piece), sized for a streetwear front-print graphic.

## Notes

- Style itself = traditional/heritage art, not owned by anyone. Safe to
  recreate originally. Don't market any output as "authentic handmade
  [X]" — several of these carry a GI (Geographical Indication) tag
  protecting that specific claim for registered artisans.
- Flat/solid backgrounds above are deliberate — makes background removal
  clean for print-ready transparent PNGs (see NARAYAN tee workflow).
- Bandhani/Ajrakh is written as a tileable all-over pattern, not a
  cutout subject — different print placement (full garment or panel,
  not a centered chest graphic).
